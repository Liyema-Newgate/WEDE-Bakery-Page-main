Final Poe Changelog and feature summary: 
# Wendy's Sweet Treats  
A modern, responsive bakery website showcasing cakes, cupcakes, pastries, and dessert items.  
The site includes a product display grid, gallery with lightbox, enquiry form, contact form, and a full shopping cart + checkout system.

---

## Features

### Home Page
- Product grid with 8+ bakery items  
- Add-to-cart functionality  
- Keyword search and category filtering  
- Smooth animations and responsive layout  

### Shopping Cart
- Add/remove items  
- Cart modal  
- Price calculation  
- Checkout modal with form validation  

### Gallery Page
- High-quality product images  
- Responsive grid layout  
- Full-screen lightbox viewer  

### Contact Page
- Contact form with HTML5 validation  
- Message type selector  
- Auto-generated email using `mailto:`  

### Enquiry Page
- Dedicated enquiry form  
- Dynamic response based on user input  

### About Page
- Accordions for “Our Story”, “Our Values”, and “Sustainability”  

### General
- Fully responsive CSS  
- Consistent header and footer across pages  
- Modern pink/white/black theme  
- Clean UI components (buttons, forms, modals)  
- Smooth animations
